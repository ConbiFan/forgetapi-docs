    ForgetAPI Reference (v1.1.0)

    全APIのリファレンス。

    API使用上の注意

    • registerMod/getMods は軽量版、mod.register() は本格版です。用途に応じて使い分けてください。
    • save はメモリのみ（揮発性）です。永続化には achievement を使ってください。ゲーム本体のセーブは saves/*.json で管理されます。
    • texture/model/sound と resource は別ストレージです。混同しないでください。
    • ui に旧 menu の機能を統合しました。menu は後方互換エイリアスとして残っていますが、新規コードでは ui を使ってください。
    • timer は scheduler のエイリアスです。どちらを使っても同じ動作をします。
    • lang は localization の拡張です。言語切り替えには lang.setLanguage() を使ってください。
    • player.damage/heal に上限・下限チェックはありません。healthが負値になり得るため、Mod側でクランプしてください。
    • event.emit は各リスナーを safeRun で保護しています。1つのリスナーが例外を投げても他のリスナーは継続実行されますが、エラーは logger.error に記録されるのみで呼び出し元には伝播しません。
    • input APIはElectronレンダラープロセス専用です。Node.jsメインプロセスやブラウザ単体では動作しません。
    • network.send は fetch ベースです。外部HTTPリクエストが可能です。セキュリティはMod作者の自己責任です。

    Core

    getVersion()

    APIバージョンを返す。

    ForgetAPI.getVersion(); // "1.1.0"

    getInfo()

    API情報をオブジェクトで返す。

    ForgetAPI.getInfo();
// {name:"ForgetAPI", version:"1.1.0"}

    safeRun(callback, modName)

    エラーを隔離して実行。例外時null返却。

    ForgetAPI.safeRun(() => {
    // 危険な処理
}, "MyMod");

    registerMod(mod)

    Modを登録（軽量版）。通常はローダーが自動呼出。

    ForgetAPI.registerMod({
    name: "MyMod",
    version: "1.0.0",
    instance: modInstance
});

    Logger

    logger.info(msg) / warn(msg) / error(msg)

    ForgetAPI.logger.info("loaded");
ForgetAPI.logger.warn("deprecated");
ForgetAPI.logger.error("not found");

    getLogs()

    全ログ履歴を配列で返す。

    ForgetAPI.getLogs();
// [{type, message, time}, ...]

    Event

    event.on(name, callback)

    ForgetAPI.event.on(
    "achievementUnlock",
    (data) => console.log(data.id)
);

    event.emit(name, data)

    ForgetAPI.event.emit("myEvent", {key: "val"});

    event.off(name, callback)

    ForgetAPI.event.off("myEvent", cb);
