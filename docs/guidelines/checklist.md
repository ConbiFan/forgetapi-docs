# Mod配布前チェックリスト

## 必須項目

- [ ] mod.jsonの全必須フィールド記入済み
- [ ] apiが最新ForgetAPIと一致
- [ ] .fmが正常に解凍できる
- [ ] 解凍後にmod.jsonが直下に存在
- [ ] ゲームがクラッシュしないことを確認

## 推奨項目

- [ ] descriptionに日本語の説明がある
- [ ] セーブデータへの影響を明記
- [ ] 他Modとの競合について記載
- [ ] アンインストール手順が明記

## 禁止事項

- [ ] 悪意のあるコードを含まない
- [ ] ユーザーの個人データにアクセスしない
- [ ] 明示的許可なくネットワーク通信しない
- [ ] 他Modのデータを勝手に書き換えない
