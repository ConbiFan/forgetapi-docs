# Mod配布前チェックリスト

## 必須項目

- [ ] `mod.json` の全必須フィールド記入済み
- [ ] `api` が `"2.0.0"` に設定されている
- [ ] `.fm` が正常に解凍できる
- [ ] 解凍後に `mod.json` が直下に存在
- [ ] ゲームがクラッシュしないことを確認
- [ ] `network.send` を使用している場合、`try/catch` でエラー処理している

## 推奨項目

- [ ] `description` に日本語の説明がある
- [ ] セーブデータへの影響を明記
- [ ] 他Modとの競合について記載
- [ ] アンインストール手順が明記
- [ ] v2.0.0 の破壊的変更に対応している

## v2.0.0 新機能の使用

- [ ] 永続保存に `storage` を使用（`save` は揮発性）
- [ ] `player.inventory()` の戻り値を直接変更せず、`player.addItem` を使用
- [ ] `item.give` が実際にインベントリへ付与することを考慮
- [ ] `world.setFog` の戻り値が `{density: 数値}` であることを考慮

## 禁止事項

- [ ] 悪意のあるコードを含まない
- [ ] ユーザーの個人データにアクセスしない
- [ ] 明示的許可なくネットワーク通信しない
- [ ] 他Modのデータを勝手に書き換えない
- [ ] ゲームルート外へのファイルアクセスを試みない（サンドボックスでブロックされる）
